# 🎬 Movie Recommendation System

## Project Overview

This project is a content-based movie recommendation system.
It recommends movies similar to a movie selected by the user.

## Objective

The objective of this project is to recommend similar movies
using movie genres, keywords and overview.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Machine Learning Technique

Content-Based Recommendation System

## Dataset

TMDB 5000 Movie Dataset

## Methodology

1. Load the movie dataset
2. Clean the data
3. Combine movie features
4. Convert text into numerical vectors
5. Calculate similarity between movies
6. Recommend the top 5 similar movies

## Result

The system successfully recommends five movies
similar to the movie entered by the user.
